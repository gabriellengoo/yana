How to log in to Sanity

1. Go to the Sanity Studio link for the site.
2. Log in with the email address that has been invited to the Sanity project.
3. If Sanity asks for a code or magic link, check that same email inbox.
4. Once you are in, you will see the Content menu.

Where to make changes

Home page:
Open Content, then Home Page. Edit the Introduction Statement, hero image, or featured projects. Press Publish when done.

Powered By Yana:
Open Content, then Powered By Yana Page. Edit the introduction copy and selected projects. Press Publish when done.

World Building:
Open Content, then Site Page, then the /world-building page. Edit the introduction copy there. Add posts under World Building Post.

Info:
Open Content, then Info Page. Edit the bio, email, services, clients, collaborators, and any extra sections. Press Publish when done.

Work/projects:
Open Content, then Project. Click the project you want to change. You can update the title, description, roles, images, video, credits, and content blocks. Press Publish when done.

Images:
Open the project or page you want to edit, click the image field, upload or choose the image, then Publish.
